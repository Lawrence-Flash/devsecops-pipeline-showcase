# Security

This repository is a **personal lab project**. It is not a production service, it does not hold customer data, and the API key checked into the Helm values (`lab-demo-key`) is a placeholder for the lab.

Please do not open issues that include real credentials.

If you find a problem in the pipeline or the sample application, open a GitHub issue. There is no bug bounty.

Secret scanning, Dependabot alerts, and branch protection are repository settings. The workflow files in this repo do not turn those on by themselves.
